# ADR-007 実AWSで検証する範囲と予算

ステータス: Proposed（未決定）

## コンテキスト

IAM、Bedrockの推論、Bedrock Guardrails、スロットリングはローカルでは確かめられない。実AWSで何をどこまでやるか、いくらまで使うかを決める。

## 決めること

| 項目 | 候補 |
| --- | --- |
| 検証対象 | IAM最小権限、Bedrockの品質比較、Bedrock Guardrails、GenUとの構成比較 |
| 月の上限額 | 未定 |
| アラート | AWS Budgetsのしきい値と通知先 |
| 使い方 | 検証のたびに立てて壊す / 一部を常設する |
| 使わないサービス | 常時課金のもの（Kendraなど） |

## 判断材料・確認すること

- [ ] 検証1回あたりの費用をM5で実測する
- [ ] 破棄し忘れを防ぐ手順（cdk destroyの自動化など）

## 決定

未定。
